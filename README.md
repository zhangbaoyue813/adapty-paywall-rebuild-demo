# 购买页可视化搭建工具 Demo

这是一个从 0-1 设计的购买页可视化搭建工具 Demo，主要解决购买页文案、卖点、价格、权益等内容调整频繁依赖开发的问题。

虽然当前示例以会员购买页为主要场景，但它与电商中的商品详情页配置、活动页搭建、营销落地页和运营后台有相近的产品逻辑。

## 在线演示

https://zhangbaoyue813.github.io/adapty-paywall-rebuild-demo/

## 项目能力

- 组件化配置页面结构、文案、卖点、价格和权益
- 三栏可视化编辑器与 iPhone 真机尺寸预览
- 拖拽排序、模版切换、多页面方案管理
- 动态变量模拟与配置 JSON 查看
- 支持新客引导、功能解锁、活动促销、到期挽留等场景

## 本地运行

```bash
npm install
npm run dev
```

本地服务默认地址：`http://localhost:3017`
